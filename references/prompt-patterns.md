# Prompt Patterns

Use short, concrete prompts for the first image.

## Cover

```text
一张中文播客封面，主题是 AI 编程，新手友好，暖色调，干净排版。
```

## Product visual

```text
一张 SaaS 产品官网 hero 插图，表达自动化工作流，简洁、现代、浅色背景。
```

## Game asset

```text
一个 2D 像素风小游戏主角，蓝色外套，背着小背包，透明背景。
```

## Edit existing image

```text
基于这张产品截图，改成更适合作为官网 hero 的视觉图：保留核心界面轮廓，背景更干净，光线更柔和。
```
